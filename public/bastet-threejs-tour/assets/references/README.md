# Direct visual-reference catalog

This catalog implements the folder structure requested in the shared ChatGPT
conversation. It records museum object numbers and the user-supplied book
figures without claiming that every missing surface or wall position is known.

- `01_Osorkon_II_Sed_Festival`: Louvre E 10592, Penn Museum E225, and the
  supplied Figure 18 gateway reference.
- `02_Nectanebo_II_Naos`: British Museum EA1078, EA1079, EA1080, and the
  supplied Figure 37/38 naos reconstruction reference.
- `03_Nectanebo_Door_and_Ceiling`: supplied Figures 33 and 34.

Museum images are not redistributed. Each subfolder provides authoritative
object-page links; only images supplied by the user in `التعديلات.docx` are
copied into this project.
