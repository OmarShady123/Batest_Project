# معبد باستت في تل بسطة — Three.js V14

نسخة V14 مبنية مباشرة على V11، وسلسلة النموذج المعماري الأساسية تعود إلى V8. لا تتضمن هذه النسخة إضافات الخط الزمني أو Evidence Mode الخاصة بـV9.

## أبرز تحسينات V14

- تحسين الإضاءة الداخلية لتقليل ظهور أسفل الأسقف باللون الأسود.
- إضافة خامات مخصصة لأسفل الأسقف مع إضاءة خافتة محافظة.
- تحسين خامات الحجر الجيري والحجر الرملي والجرانيت الأحمر والحجر الداكن.
- تحسين إعدادات الظلال وShadow Bias ورفع دقة خريطة الظلال.
- تحسين كاميرات المدخل وبوابة أوسركون والفناء الحتحوري وقدس الأقداس.
- جعل وضع المشي أكثر سلاسة عبر التسارع والتباطؤ التدريجيين.
- تثبيت ارتفاع العين عند مستوى أقرب للإنسان وتحسين التصادمات حول الجدران والأعمدة.
- إخفاء الواجهة والعلامات تلقائيًا أثناء المشي وإظهار علامة تصويب صغيرة فقط.
- حفظ PNG بدقة أعلى مع استعادة إعدادات العرض بعد الحفظ.

## التشغيل

شغّل المشروع عبر خادم محلي لأن Three.js يستخدم ES Modules:

```bash
cd bastet-temple-threejs-v12-final-visual-walkthrough-polish
python -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

أو:

```bash
npm start
```

## التحكم

- العرض العادي: سحب الماوس لتدوير الكاميرا.
- **وضع المشي**: للدخول إلى التجول الداخلي.
- `W`: للأمام.
- `S`: للخلف.
- `A` و`D`: حركة جانبية.
- `Shift`: زيادة السرعة.
- `Esc`: تحرير الماوس من وضع التوجيه.
- **وضع العرض**: إخفاء الواجهة مؤقتًا.
- **حفظ PNG**: إخراج صورة بدقة أعلى.
- **تصدير GLB**: تصدير النموذج من المتصفح.

## تصدير GLB من Python

```bash
pip install trimesh pillow numpy
python export_glb_v12.py
```

الناتج:

```text
exports/bastet-temple-bubastis-v12-final-visual-walkthrough-polish.glb
```
